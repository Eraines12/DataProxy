# A03 - Neural Network Zoo

## The CNN Eagle

**Course:** ITAI 2376<br>
**Team:** Data Proxy

## Project Overview

Our team used an eagle to represent a Convolutional Neural Network (CNN). Eagles are known for strong vision and noticing small details, which connects to how CNNs recognize visual patterns in images.

This project covers:

- Neural Networks
- Deep Learning
- CNN Layers
- Convolution
- Filters and Feature Maps
- Pooling
- Flattening
- Backpropagation
- Real-World CNN Applications

## Main Takeaway

CNNs are designed to recognize visual patterns. They learn simple features such as edges and lines first, then build those features into more detailed patterns before making a final prediction.
