## Project Overview

Team DataProxy analyzed how the communication problems in *Arrival* connect to Natural Language Processing. We examined how meaning depends on context, culture, intention, repetition, visual information, and pattern recognition.

The project also compares the movie's communication methods with rule-based NLP, statistical NLP, deep NLP, machine translation, language models, and other real-world tools.

## Main Takeaway

Our main lesson from *Arrival* is that translating words is only one part of communication. NLP can identify patterns and suggest possible meanings, but context, culture, cooperation, and human judgment are still necessary to avoid misunderstandings.
