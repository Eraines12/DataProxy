# A04 - Weights, Bias, and Activation Functions

## Wizards vs. Aliens

**Course:** ITAI 2376<br>
**Team:** DataProxy

## Project Overview

Our team created a Wizards vs. Aliens game to explain how a neural network makes a decision. The wizard studies clues such as health, armor, and how close the alien boss is before choosing whether to attack or wait.

The presentation uses stars to make the main concepts easier to understand:

- **Weights:** Stars show which clues matter most. Health receives more stars because it has more influence on the decision.
- **Bias:** A bonus star gives the wizard an extra push before making the final choice.
- **Activation function:** The final rule counts the stars and decides whether the wizard should attack or wait.
- **Decision:** Three or more stars means attack. Two or fewer stars means wait.

The project also includes an interactive game and connects the lesson to real AI examples, including game AI, voice assistants, and self-driving cars.
