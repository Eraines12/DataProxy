## Project Overview

This project compares two major approaches to using artificial intelligence: **open-source and self-hosted AI infrastructure** (Hugging Face Transformers) versus **proprietary cloud APIs** (OpenAI GPT-4). 

The goal is to analyze the trade-offs between these approaches across multiple dimensions including ease of use, privacy, cost, scalability, customization, and real-world applications. This report is designed for college-level technical audiences.
